# Insurance Claims Anomaly Detection & Fraud Risk Scoring

## Project Overview
This project focuses on identifying unusual insurance claims and detecting potential fraudulent activities using machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Isolation Forest
- PySpark
- SQL
- SHAP

## Key Features
- Insurance claims data preprocessing
- Feature engineering
- Anomaly detection
- Fraud risk scoring
- Machine learning classification
- Model evaluation using Precision, Recall and F1-score
- Model explainability using SHAP

## Project Objectives
- Identify unusual insurance claims.
- Detect suspicious claim patterns.
- Prioritize high-risk claims for investigation.
- Improve fraud detection through predictive analytics.
